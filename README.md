🤖 Bot Discord IA
Bot multifuncional para Discord com inteligência artificial, sistema de economia e ferramentas administrativas.
✨ Funções
🧠 Perguntas e respostas com IA
📚 Histórico automático de perguntas
💰 Sistema de pontos e saldo
🎁 Recompensa diária
🎰 Roleta de apostas
👤 Perfil dos usuários
🔐 Comando administrativo protegido
💬 Painel no CMD para enviar mensagens
🗑️ Exclusão da última mensagem enviada pelo bot
🧹 Limpeza automática de canais duplicados
📝 Registro de ações administrativas
📁 Estrutura
O projeto utiliza apenas dois arquivos principais:
main.py — código principal do bot
.env — configurações e chaves de acesso
Os demais arquivos, como histórico, memória, usuários e registros, são criados automaticamente pelo bot durante o uso.
